# 🍕 Pizza Sales SQL Analysis

## 📌 Project Overview
This project analyzes pizza sales data using SQL to extract meaningful business insights.  
The dataset includes orders, order details, pizza types, and pricing information.

---

## 🗂 Database Tables
- **orders** – Order date and time  
- **order_details** – Quantity of pizzas per order  
- **pizzas** – Pizza size and price  
- **pizza_types** – Pizza name, category, ingredients  

---

## 📊 Analysis Performed

### 🔹 Basic Analysis
- Retrieved the total number of orders placed
- Calculated total revenue generated
- Identified the highest-priced pizza
- Determined the most commonly ordered pizza size
- Found the top 5 most ordered pizza types

### 🔹 Intermediate Analysis
- Calculated total quantity ordered per pizza category
- Analyzed order distribution by hour of the day
- Determined category-wise pizza distribution
- Computed average pizzas ordered per day
- Identified top 3 pizzas by revenue

### 🔹 Advanced Analysis
- Calculated revenue percentage contribution by pizza type
- Analyzed cumulative revenue over time (window functions)
- Determined top 3 revenue-generating pizzas within each category (ranking functions)

---

- SQL Joins
- Aggregations (SUM, COUNT, AVG)
- GROUP BY & ORDER BY
- Subqueries
- Window Functions (RANK, SUM OVER)
- Business Data Analysis
